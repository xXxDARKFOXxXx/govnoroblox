# StudEggs для Roblox Studio

Десять морских яиц по уровням от 01 до 10. В каждом GLB уже есть текстуры, рельеф, скелет и зацикленная анимация на месте. У старших яиц есть подвижные детали, светящиеся вставки и вращающиеся элементы. Частицы и цветной свет в Roblox создаёт отдельный StudEggsRuntime.

Размеры указаны в студах при выборе **Scale Unit → Studs**. Порядок в таблице — длина × ширина × высота, включая декор.

## Установка

1. Распакуй ZIP. В Roblox Studio открой **File → Import** и выбери файл GLB. Для первого теста можно взять 01_Tide.glb. В окне импорта выбери **Rig Type → Custom** и включи **Add to Workspace**.
2. В **Explorer** раскрой модель яйца внутри **Workspace** и выбери её **MeshPart**. В панели **Properties** введи в поиск **Anchored** и поставь галочку. Если панели скрыты, открой **Window → Explorer** и **Window → Properties**.
3. Открой [StudEggsRuntime.txt](StudEggsRuntime.txt) в Блокноте и скопируй весь текст. В **Explorer** раскрой **StarterPlayer**, нажми **+** рядом со **StarterPlayerScripts** и выбери **LocalScript**. Назови его **StudEggsRuntime**, открой и замени стандартный текст скопированным кодом.
4. Нажми **F5** и подойди к яйцу. Движение и эффекты видны рядом с моделью. Всплески у старших яиц повторяются через несколько секунд.

В StarterPlayerScripts скрипты StudfishRuntime и StudEggsRuntime должны находиться рядом. Для всех десяти яиц достаточно одного StudEggsRuntime. Его также можно вставить в виде StudEggsRuntime.rbxmx через контекстное меню Explorer, если в твоей версии Studio доступно **Insert From File…**.

Если модель есть, но она стоит неподвижно, проверь в Explorer кость с именем StudEgg_01_Tide для первого яйца. При отсутствии кости импортируй GLB с типом рига **Custom**.
