## 1. Добавь рыбу в сцену

Если у тебя уже установлены первые четыре рыбы, оставь их в сцене и импортируй только новые модели. Для новых рыб понадобятся шаги 1 и 2, а общий скрипт обновляется один раз на шаге 3.

1. Распакуй ZIP. Открой проект в Roblox Studio и нажми **File → Import**. Для первой проверки новой рыбы выбери `Jelly.glb`.
2. В окне предварительного просмотра выбери **Rig Type → Custom** и включи **Add to Workspace**. Если хочешь сохранить размер из таблицы, оставь **Scale Unit → Studs**. Нажми **Import**. Когда первая рыба заработает, таким же способом можно добавить остальные.

## 2. Закрепи рыбу, чтобы она висела на месте

1. Открой **Window → Explorer** и **Window → Properties**, если этих панелей ещё не видно. В **Explorer** раскрой стрелку рядом с `Workspace`, затем стрелки у модели рыбы.
2. Выбери деталь внутри модели. В заголовке окна **Properties** должен появиться тип **MeshPart**. Если там написано **Model** или **Bone**, выбери саму деталь внутри группы.
3. В строке **Filter Properties** введи `Anchored` и поставь галочку. Для той же детали можно использовать кнопку с якорем **Home → Anchor**. Она переключает состояние, поэтому если галочка уже стоит, оставь её включённой.

## 3. Вставь текст скрипта

Окно, в котором доступны OBJ и glTF, предназначено для 3D-моделей. Для скрипта создай **LocalScript** прямо в Explorer.

1. Открой [StudfishRuntime.txt](StudfishRuntime.txt) в Блокноте. Нажми **Ctrl+A**, затем **Ctrl+C**.
2. В **Explorer** раскрой **StarterPlayer**. Наведи мышь на строку **StarterPlayerScripts** и нажми **+** рядом с ней. В поиске введи **LocalScript** и выбери его.
3. Дважды щёлкни по новому **LocalScript**. Щёлкни внутри редактора кода, нажми **Ctrl+A**, затем **Ctrl+V**. Скопированный текст заменит пример, который Studio вставляет в новый скрипт.
4. Одного LocalScript достаточно для всех 20 моделей. Если у тебя уже работает скрипт для первых четырёх, открой его и замени весь текст новым содержимым StudfishRuntime.txt.

## 4. Проверь результат

Нажми **F5** (**Test**, кнопка ▶) и подойди к рыбе. Проверь движения и частицы рядом с моделью. Фонтан кита появляется примерно раз в шесть секунд. В режиме **Run** по F8 игрок не появляется, поэтому проверяй через **F5**. Для выхода из теста нажми **Shift+F5**.

Если рыба видна, но стоит неподвижно, введи `StudFish_` в поиск **Explorer**. Например, у медузы должна найтись кость `StudFish_Jelly` внутри её `MeshPart`. Если кости нет, проверь **Rig Type → Custom** при импорте исходного GLB. Если кость на месте, проверь, что код вставлен именно в **LocalScript** внутри **StarterPlayerScripts**.
